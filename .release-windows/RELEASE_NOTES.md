## Windows 0.2.2：修复全屏和手机旋转提示

**Windows 10/11 x64 测试版。0.2.1 用户请下载此版本。**

下载 **`Jianpian-Windows-C-0.2.2.zip`**，完整解压后运行 `Jianpian.exe`，
保留同目录的 DLL。便携包约 **1.03 MiB**，
需要系统已安装 Microsoft Edge WebView2 Runtime。
系统运行环境、浏览器用户数据和视频缓存另占空间。

### 本次修复

- 全屏不再调用手机方向锁，不再提示“请旋转手机观看”。
- 播放器内部按钮、下方“全屏播放”、工具栏和 F11 统一切换桌面全屏。
- 全屏播放器铺满视口，详情和讨论不会覆盖画面。
- Esc / F11 / 右上角“退出全屏 (Esc)”恢复原来的小播放器和详情布局。
- 切换时保留视频节点和播放状态，视频保持原比例。

已用真实 1080p 视频验证全屏尺寸、九点遮挡检测、连续播放和退出还原，
并手动验证各个全屏入口。新增 8 项全屏回归检查，
原有 32 项地址、40 项缓存/路径、11 项播放清单、9 项下载控制器检查通过。

支持自定义视频路径和自动创建文件夹、普通 HLS 边下边播与整集保存。
原版 P2P 内核未移植；不合并 MP4。直播、独立音轨、字节范围 HLS、
DRM 不支持整集保存。账号登录、全部线路和完整长片离线播放尚未验证。

最终运行目录和最终便携 ZIP 经 Defender 重新扫描未检出威胁；
微软 DLL 签名有效，**EXE 尚无 Authenticode 签名**。
扫描结果不构成绝对安全保证。

附件包含便携包、源码与检查记录、发布检查报告和 `SHA256SUMS.txt`。
源码及构建说明同步到发布标签；构建仍需指定原始 APK、编译器及 SDK，
原厂完整前端工程未随本项目提供，第三方许可及权利仍适用。
