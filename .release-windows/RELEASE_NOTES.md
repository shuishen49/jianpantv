# Windows C 桌面版 0.2.3：确认后更新

发布日期：2026-11-15（Asia/Shanghai）。Windows 10/11 x64 测试版，需已安装 WebView2 Runtime。

下载 `Jianpian-Windows-C-0.2.3.zip`，完整解压后运行 Jianpian.exe，并保留同目录的 DLL。
便携 ZIP 约 1.04 MiB。`Jianpian-Windows-C-0.2.3.exe` 是程序内更新附件，
首次安装应使用 ZIP。0.2.2 及更早版本需先手动升级本版一次。

## 更新行为

- 启动约 8 秒后后台检查，运行中每 4 小时检查；工具栏可随时“检查更新”。
- 只筛选此仓库的 Windows 版本，按数字比较，过滤 TV、草稿和缺少更新附件/摘要的版本。
- 固定更新清单优先，GitHub Release API 备用；清单随主分支在 Release 发布成功后更新。
- 发现新版显示版本、大小并询问，默认“否”；确认后下载并验证大小、SHA-256、x64 PE、
  内嵌版本和加载器兼容性，再关闭、替换并重启。安装会停止当前播放和下载。
- 保留视频、缓存和保存路径。真实子进程测试验证替换及启动失败回退。
- 同目录短暂保留旧版和原生更新进程，成功后清理；不执行远程脚本或系统命令，不申请管理员权限。
- 下载中断、目录不可写或校验失败保留原版本；运行环境变化时需完整解压新便携包。

保留 0.2.2 的桌面全屏修复、TV 风格小播放器、自定义目录和普通 HLS 边下边播。
这属于需要重启的程序内更新。

## 验证与边界

65 项更新检查、4,000 组异常 JSON 输入，以及真实 ReplaceFile/继承句柄/启动握手和回退测试通过。
更新提醒使用显式 0.2.4 样本运行生产弹窗，实际检查按钮和联网失败提示单独验证。
发布前的 API 请求曾遇到 GitHub 限流；不会把样本检查当作完整线上更新链路。
发布后的真实更新记录若已完成，将另存 testing/windows-native-0.2.3/github-live-update.json。
原有 32 项地址、40 项缓存路径、11 项播放清单、9 项下载及 8 项全屏回归检查通过；
本版实际 1080p 播放、全屏连续性、紧凑布局和边下边播由最终 EXE 烟测验证。
本次烟测额外媒体请求失败数：1。
报告完整保留计数；解码、播放进度和功能断言分别检查，不宣称全部媒体请求成功。
UI 基线保留原测试版本。尚未验证全部线路、账号登录及完整长片离线播放。

最终 EXE 无 Authenticode 签名。微软 DLL 签名有效，最终运行目录及 ZIP 由 Defender
扫描未检出威胁；扫描不构成绝对安全保证。更新摘要信任仓库维护者，不是独立代码签名。

原版 P2P 内核未移植；HLS 保存为 m3u8 + media，不合并 MP4。
直播、独立音轨、字节范围 HLS、DRM 不支持整集保存。系统运行环境、浏览器数据和视频缓存另占空间。
源码包的 26 个 C/JS/CSS/构建文件逐字节对应标签；构建需固定原始 APK、编译器和 SDK，
这些输入及原厂完整前端工程不随包提供，第三方许可及权利仍适用。
