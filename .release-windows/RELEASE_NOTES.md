# Windows C 桌面版 0.2.4：全屏方向键与单个 MP4

发布日期：2026-11-15（Asia/Shanghai）。Windows 10/11 x64 测试版，需要已安装 WebView2 Runtime。

下载 `Jianpian-Windows-C-0.2.4.zip`，完整解压后运行 Jianpian.exe，并保留微软 DLL。
ZIP 1.59 MiB，完整目录 2.38 MiB；
浏览器运行环境、用户数据和视频缓存另计。
0.2.3 可用“检查更新”，旧版须手动下载本版 ZIP。

## 新增行为

- 全屏时 ← 快退 10 秒，→ 快进 10 秒。暂停/播放状态保留，边界限于可跳转范围。
- “缓存整集（MP4）”下载完当前 HLS 点播资源后，自动合并成单个 MP4。
  文件名包含片名及地址摘要，保存在用户选择的目录中，可单独复制和播放。
- 原 C 宿主内静态链接裁剪的 FFmpeg 9.0.2 容器组件，无重编码；无额外 FFmpeg EXE、
  浏览器或安卓运行环境。原始 Windows 客户端没有参与构建。
- 普通 H.264/AAC TS、AES-128 与初始化分片有短样本验证；逐个核对缓存摘要，
  写完索引并刷盘、原子发布后才报告成功。失败或取消不发布半成品，也不替换旧 MP4。
- 合并成功删除本次中间清单，media 缓存保留供播放和重试。旧版已有 m3u8 不自动批量转换；
  重新保存可复用地址/范围匹配的完整缓存。
- 保存位置设置、目录自动创建、右侧详情/讨论、F11/Esc 和 GitHub 确认后更新继续保留。
