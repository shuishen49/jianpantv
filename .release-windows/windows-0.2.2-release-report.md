# Windows C 客户端 0.2.2 全屏修复与验证

发布日期：2026-11-14（Asia/Shanghai），标签 `v0.2.2-windows`。
适用 Windows 10/11 x64，需要已安装 Microsoft Edge WebView2 Runtime。

## 修复内容

0.2.1 仍使用 Android 页面的方向锁与旋转回退；桌面不支持方向锁时会提示
“请旋转手机观看”。原生工具栏 / F11 也仅扩大宿主窗口。

0.2.2 将 APK 中实际使用的全屏进入、退出和 resize 辅助函数替换为桌面控制器。
播放器内按钮、播放器下方按钮、工具栏和 F11 统一进入 Win32 全屏并将播放器铺满视口；
Esc / F11 / 右上角退出按钮恢复小窗布局。不调用手机方向锁，也不执行伪横屏旋转。
全屏时隐藏详情、讨论和缓存面板，避免其叠加在视频上。
不重新创建或挂载视频节点，视频保持原比例。

## 保留限制

原版 P2P 内核未移植；普通 HLS 点播可边下边播和保存整集 `.m3u8`，
不合并 MP4。直播、独立音轨、字节范围 HLS、DRM 不支持整集保存，
直连 MP4 不走此流程。没有本地影片库或退出后后台下载。
账号登录、全部线路及完整长片离线播放尚未验证，播放可用性依赖原服务。

构建需要固定摘要的原始 Android APK、Zig C 编译器和官方 WebView2 SDK；
这些输入不在源码包内。原厂完整前端工程未提供。
详见 `docs/windows-native-build.md`。原应用及第三方组件的许可与权利仍适用。
