# Windows C 桌面版 0.2.6：新图标与桌面界面、MP4 命名和缓存清理

发布日期：2026-11-15（Asia/Shanghai）。Windows 10/11 x64 测试版，需要已安装 WebView2 Runtime。

下载 `Jianpian-Windows-C-0.2.6.zip`，完整解压运行 Jianpian.exe，并保留微软 DLL。
便携 ZIP 1.71 MiB；完整目录 2.50 MiB。
0.2.3 及以上可在程序内“检查更新”。既有 MP4 和保存路径保留。

## 变更

新设计的红色播放图标统一用于 EXE、Windows 标题栏、任务栏与网页品牌区，
ICO 包含 16/20/24/32/40/48/64/128/256 像素，图像和资源全部嵌入 EXE。
保留生成原图和提示词；运行时不下载图标，不增加 UI 框架或浏览器依赖。
原生工具栏换成统一线形小图标，页面使用深色珊瑚红配色，
改善侧栏和搜索框，首页大图高度缩小，使常用入口及影片列表更早出现。

成品示例：`《八仙！》-1080p-国语.mp4`；剧集保留已知集数。
清晰度从实际视频短边像素读取，存在多个规格时按累计时长选主要规格，
不从播放器显示尺寸或插入的短片画面猜测。无法读取清晰度或语言时省略对应字段。
使用所选音轨或影片明确的语言信息，常见语言代码转中文，不从地区推测。
下载开始时记录片名/集数/语言，切换页面不会改变正在保存的文件名称。
移除品牌前缀和地址摘要；非法字符替换、过长名称安全截短。
原子发布不覆盖同名文件，冲突时追加 ` (2)`、` (3)` 等序号；既有成品不会自动重命名。

完整 MP4 通过音视频包、时长与缓存摘要校验，完成尾部索引、刷盘并原子发布后，
关闭合并器输入，再删除本集 m3u8、media 中对应的 .ts / .info。media 为空时删除空目录。
播放响应已经读入内存后仍然有效；本次运行中晚到的响应不再写回已完成分片。
重新在线播放可能需要联网；成品 MP4 可独立离线播放，尚无本地影片库入口。

下载前登记本集所有资源，包含 AES 密钥及初始化片段，保护其他未完成下载的共用分片。
共用或占用的文件稍后重试，恢复记录在下次选择该目录时继续处理。
对应成品不存在或大小变化时保留缓存；恢复记录无法写入时提示检查权限并重新保存。
只处理本集列出的摘要文件，保留其他内容；不递归清空目录，不跟随 media/文件重解析点。
合并失败、停止和取消保留恢复用分片与旧 MP4。显式重试允许重新缓存。
保留 HLS 切换修复、全屏方向键 10 秒、暂停状态、详情/讨论布局及确认后更新。

## 验证

- 28 项 MP4 检查：H.264/AAC 包数与时长、AES、初始化段、切换时间轴、损坏/缺片拒绝、
  成品命名、重复保存不覆盖、取消与旧文件保留，以及成功清理、失败/取消保留缓存。
- 61 项原生清理检查：并发读写、晚到写入、显式重试、共用的未完成下载、真实文件占用、
  新旧文件名的恢复记录、无成品时保留缓存、其他文件及成品保留。
- 28 项命名检查覆盖 Unicode、未知字段、语言代码、安全文件名及有界元数据；
  25 项下载/标题检查包括从固定 APK 实际改写的标题渲染器读取语言与集数、
  音轨优先、缺失信息、下载中切换页面及错误/取消状态。
- EXE 中九种尺寸图标资源与源码 ICO 逐个核对；网页图标与构建清单一致。
- 以下整集数据属于此前 0.2.6 开发构建的历史验证，保留原 EXE 摘要和时间戳，
  未冒充最终图标/命名构建的新测试：372 个分片、56 个切换标记，
  隔离合并耗时 11.0 秒，
  成品 217.88 MiB、时长 1484.856 秒。
  35,617 个视频包和 69,529 个音频包保留；1/298/300/316/318/1483 秒的系统音视频解码与跳转通过。
  测试副本的分片、元数据、清单及空目录随后全部自动清理。未逐帧解码整集，不分发测试媒体。
- 最终 EXE 在线 1080p 播放、暂停、跳转、全屏连续性、900×640 布局、右侧滚动、
  边播边存及停止通过。媒体烟测有 1 个额外请求失败，
  实际播放断言通过。地址/路径/清单/下载/全屏/更新回归通过，包括 4,000 组异常 JSON 与实际替换/回退。
- 物理全屏按钮、F11/Esc、左右键及手动更新入口保留原 0.2.4 的独立历史 UI 记录，
  不宣称已在本版重新输入。对应原生全屏函数、按键/命令分支、fullscreen.js、
  全屏 CSS 与更新模块按范围逐段核对，与该历史标签完全一致。
  最终 EXE 的在线铺满视口/连续性/退出、18 项输入逻辑和真实更新替换/回退在本版重跑。
  目录创建 UI 同样明确保留原测试版本，路径与缓存原生检查在本版重跑。
- LGPL 实际对象重链接及运行时校验通过。源码包含完整 FFmpeg 官方源码归档、
  签名/公钥、配置、静态库、宿主对象及资源，依 LGPL-2.1-or-later 分发。

直播、独立音轨、字节范围 HLS、DRM、原版 P2P 不支持整集保存。未验证全部线路、账号登录、
多进程同时使用同一目录。升级不自动猜测旧版 m3u8 对应的 MP4 并批量删除；重新保存后可自动清理。
WebView2 用户数据与未完成下载仍会占磁盘空间。

最终运行目录和 ZIP 的 Windows Defender 扫描未检出威胁；这是本次扫描结果。
EXE 无 Authenticode 签名，微软 DLL 的签名有效；未使用原 Windows EXE，未关闭杀毒软件。
