# Windows C 桌面版 0.2.5：修复 HLS 切换后的 MP4 合并失败

发布日期：2026-11-15（Asia/Shanghai）。Windows 10/11 x64 测试版，需要已安装 WebView2 Runtime。

下载 `Jianpian-Windows-C-0.2.5.zip`，完整解压后运行 Jianpian.exe，并保留微软 DLL。
ZIP 1.59 MiB，完整目录 2.38 MiB。
0.2.3/0.2.4 可用“检查更新”；较早版本须完整下载 ZIP。保留保存路径和已有视频缓存。

## 修复

旧版合并器把 HLS 声明的切换点当成连续 TS 字节流：计数器重置触发异常包，
插入片段前后的时间戳后退/前跳还会产生额外空白时长，最终报 -1094995529。
0.2.5 按 EXT-X-DISCONTINUITY 分区间解析，再依清单时长接回同一个 MP4 时间轴。
各区间继承有效密钥、初始化段、媒体序号及 AES-128 隐式 IV，保留 AAC 配置切换。
不修改原始缓存、不忽略损坏包标记，不重编码或删掉插入片段。
失败显示阶段或具体包/时长原因，保留已下载分片；取消保留旧 MP4。
全屏左右键 10 秒、暂停状态、详情/讨论布局、路径设置及 GitHub 更新保留。
