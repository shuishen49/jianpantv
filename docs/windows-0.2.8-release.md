# Windows C 桌面版 0.2.8：本地影片、打开文件与拖入播放

发布日期：2026-11-15（Asia/Shanghai）。适用 Windows 10/11 x64，需要已安装微软 WebView2。
完整解压 `Jianpian-Windows-C-0.2.8.zip` 后运行 Jianpian.exe，保留微软加载器 DLL。
便携 ZIP 1.72 MiB，程序目录 2.53 MiB；
浏览器运行环境、用户数据及电影文件另计。

## 使用

- 左侧和工具栏新增“本地影片”，列出当前保存目录里的视频；点击已保存的 MP4 即可离线播放。
  使用原来的 D:\jianpandownload 等保存目录，新增文件可点“刷新列表”。
- “打开文件”或 Ctrl+O 打开其他位置的视频；也可以把视频文件拖入窗口。
  把视频拖到 Jianpian.exe 图标上，或在 Windows“打开方式”中选本程序，也能直接启动播放。
  不自动修改全局文件关联。
- 本地播放器左侧列出影片，右侧播放；支持进度条、空格暂停/播放、左右方向键各 10 秒、
  双击/F11 全屏及 Esc 退出。打开本地视频时暂停原来的在线视频，返回后可继续在线浏览。
- 已打开的同一影片再次选取时保留当前播放位置/暂停状态。
- 直接按需读取原文件，不上传、不复制成第二份，也不创建本地电影的分片缓存。
  支持超过 4 GiB 文件、HTTP Range 跳转和后缀范围；路径通过进程内随机标识授权。
- 可选择 MP4/M4V/MOV/WebM/MKV，实际编码支持取决于系统 WebView2；推荐 H.264/AAC MP4。
  尚未完成下载或未合并的 HLS 分片不列为完整电影。
- 保留整集 MP4 保存、命名和成功后的缓存自动清理、观影历史、右侧详情讨论及 GitHub 更新。

  Range/HEAD/后缀范围、未知文件拒绝、列表播放、损坏视频提示、真实 File/DataTransfer DOM 拖入及释放。
  该测试模式明确阻止所有外部请求，网络/视频缓存写入均为零。
