# Windows C 桌面版 0.2.7：左侧观影历史与保存位置窗口

发布日期：2026-11-15（Asia/Shanghai）。Windows 10/11 x64 测试版，需要系统已安装 WebView2 Runtime。

完整解压 `Jianpian-Windows-C-0.2.7.zip` 后运行 Jianpian.exe，保留微软 DLL。
便携 ZIP 1.71 MiB；完整程序目录 2.51 MiB。
WebView2、浏览器用户数据和视频文件另计。0.2.3 及以上可在程序内点击“检查更新”。

## 本版修改

- 左侧增加带时钟图标的“观影历史”按钮，直接打开原有本地/账号历史列表。
  选中状态跟随路由，历史页面保留侧栏，可以返回首页或其他入口；首页不再显示重复的历史横栏。
  复用原有历史存储，未更改记录格式，不复制或迁移既有观影数据。
- 保存位置窗口重新排版：深色标题栏、文件夹图标、更清晰的标题和说明、圆角路径输入区、
  珊瑚红主按钮、深色取消按钮。聚焦输入框时显示强调色边框，错误提示位于按钮上方。
  保留真实 Win32 编辑框和按钮，支持键盘 Tab、回车确认和 Esc 取消。
- 仍可直接输入 D:\jianpandownload 等新路径，保存时自动创建多级文件夹。
  无效路径显示错误，不替换已保存设置；修改输入后清除错误。
  保存路径、原有 MP4 命名及合并后的缓存自动清理规则保持兼容。
- 宿主仍为 C17 / Win32，图形通过 GDI 绘制，未增加字体包或 UI 框架。
